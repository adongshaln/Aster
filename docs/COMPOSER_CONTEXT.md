# 输入、附件与引用

- 设置 → 助手偏好 → **回车发送**。默认开启；关闭后回车换行。开启时 Shift + 回车仍换行，输入法组合输入和生成中不通过回车发送或停止。普通聊天、剧情 RP 与展开草稿使用同一设置。
- 文本、PDF、DOCX 导入为文件卡片，保留原文件的本地副本；点卡片可用系统查看器打开。提取文字不写进可编辑草稿，也不展开到用户消息正文。发送时将文字作为参考资料加入模型请求，兼容 Chat Completions、Responses 与 Anthropic Messages；不要求服务支持原生文件上传或文件工具。
- 仍限制单文件 10 MB / 40,000 字符、PDF 200 页；每轮最多 4 个文件，附件文字合计 40,000 字符。扫描 PDF 仍需先识别文字或改传图片。
- 消息操作中的「引用追问」引用完整消息；长按选择文字后，纸面菜单中的「引用」只引用所选文本，保留原剪贴板。引用以可移除卡片显示，不改写草稿。预览可省略显示，模型收到完整引用快照。
- 文件与引用随消息保存，支持编辑重发、重新回答和失败重试。未发送卡片按对话保存并在切回或重启后恢复；开始新的空白对话会清除该空白草稿的卡片。
- 卡片使用现有纸面颜色、14dp 控件圆角、轻描边和共享弹簧；图片移除按钮的可见尺寸为 24dp，叉号 14dp，点击区域保留 48dp。关闭系统动画时不播放新增动效。

验证入口：`ChatComposerContextTest`、`MainViewModelStateTest`、`DocumentImportTest`；设备端 `ComposerContextInteractionTest` 检查键盘、卡片、删除区域、选区引用与剪贴板，并留存浅色、深色大字号和选择菜单截图。
