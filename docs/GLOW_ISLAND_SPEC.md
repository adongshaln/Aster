# 链接岛发光圆环设计规格（用户 2026-10-13）

目标：把它做成"会发光的光圈"，而不是"画上去的边框"。质感靠分层的光，动画靠有重量感的运动。

## 质感：四层叠加
- **黑底**：圆环内侧留 1.5dp 纯黑间隙，OLED 上等于像素熄灭，和镜头孔融为一体。外侧垫 2–3dp 黑底，发光才有暗处可发（代价：浅色界面上孔会显得略大）
- **核心线**：1.5dp 橙线，中心再叠一条更细的淡黄白线，有"灯丝"感
- **光晕**：用 3 层逐渐加宽、变淡的描边叠出来，别用实时 BlurMaskFilter（老系统费电）
- **渐变**：SweepGradient，橙 → 琥珀 → 淡黄 → 橙。旋转它的 matrix 就是流光，几乎不费性能

## 一次点击的动画叙事
1. **待机**：几乎静止，只有 3.5 秒一周期的正弦呼吸（透明度 0.75↔1）
2. **按下**：线宽 +40%、光晕增强，配 CLOCK_TICK 触感。形变只向外长，内缘固定，往里缩会被镜头孔"吃掉"
3. **识别**（约 0.5 秒，动作并行启动，不等动画）：带拖尾的亮弧绕一圈，收束时闪光并换色。在最亮的瞬间换色，看不到混浊的过渡色

## 手感
- 按下用弹簧（阻尼比约 0.5，带一点过冲），其余用强减速，只有流光旋转可以线性。
- 触感和视觉峰值相差别超过 30ms，同一时刻只让一个动画当主角。

## 省电
- 静态层只改 alpha，不触发重绘。全屏、息屏时暂停，系统关闭动画时直接变色。

## 架构
- **渲染是状态的纯函数**：View 里只存几个浮点参数（`glow`、`width`、`colorMix`、`headAngle`、`progress`、`rippleT`），`onDraw` 只按参数画，不写逻辑，动画只负责改参数。之后加状态、调手感都不会牵一发动全身。
- **待机零重绘**：静态光晕放进单独的 View（`LAYER_TYPE_HARDWARE`），呼吸只改它的 `alpha`，不触发 `onDraw`。只有交互和处理中才逐帧刷新。
- **窗口越小越好**：按涟漪最大范围定尺寸，窗口内的触摸下层应用收不到。若要做大的纯特效窗口（`FLAG_NOT_TOUCHABLE`），Android 12+ 要把它的 `alpha` 设为 ≤0.8，否则会挡住下层触摸。

## 质感细节
- **用色温做层次**：真实光源中心偏白、边缘偏饱和。核心线 `#FFF3D6`，主体 `#FFB020`，光晕 `#FF6A00`（透明度 0.35 渐隐到 0）。
- **光晕用 ADD 混合**：叠加处自然变亮发白，像真的在发光。
- **最好的方案是 AGSL**（API 33+）：一个 shader 画整个光环，算每个像素到圆环的距离 `d`，核心 = `1 - smoothstep(0, w, d)`，光晕 = `exp(-d·k)`。没有层叠的台阶，所有状态都只是传 uniform，暗部色带用极轻的噪声抖动抹掉。
- **低版本回退**：3 层不同宽度的描边加 `SweepGradient`，首尾同色，流光只转 local matrix，不要每帧重建 shader。

## 手感细节
- **按下和回弹用弹簧**：androidx 的 `SpringAnimation`，阻尼比 0.5。快速连点时会保留当前速度，不会"跳"。
- **处理中的弧线学 Material 的不确定进度条**：亮弧长度在约 40° 到 220° 间伸缩，同时整体旋转，比匀速转动耐看得多。
- **进度值别直接赋值**：用指数平滑追踪目标值（只增不减），否则下载进度一跳，弧头就一抖。
- **触感用 `VibrationEffect.createPredefined`**（TICK/CLICK，API 29+，需 VIBRATE 权限）。悬浮窗里的 `performHapticFeedback` 可能不稳定。

## 实现顺序
先搭参数化状态机，再做质感（色温加光晕），最后调弹簧手感。涟漪曲线、换色时机、省电策略沿用上面方案。
