# 对话底部手势与回答导航

- 阅读到底后继续往下滚动（手指向上推），纸面进度圈逐步填满。提示由「继续滑动，新建会话」变为「松开，新建会话」；满圈后松手才调用既有新建会话流程，保留原会话。
- 不足阈值、反向拉回、系统取消、多指操作都不新建。惯性滚动和程序化定位不累积进度。生成中、导入附件中、聚焦输入或键盘打开时不启用。
- 阈值为阻尼后的 96dp。圈满时给一次轻触感；提示的显隐、进度与控件按压使用现有 Aster 弹簧，并遵循系统动画开关。
- 右上角为 Markdown 导出，复用原有系统保存窗口；空会话和生成中禁用。移除原顶栏新建按钮和三点操作菜单；侧栏仍可新建。
- 上一/下一回答合为右下角纸面胶囊，48dp 操作范围，按助手消息定位。胶囊随输入区高度和键盘位置移动；拉出新建进度圈时暂时隐去，避免重叠。

验证入口：`ConversationEndPullTest`、`AnswerNavigationTest`、`ChatEndNavigationInteractionTest`。设备检查使用真实 LazyColumn 触摸与取消事件，覆盖进度、松手新建、历史/草稿保留、短拉/反向/取消、禁用/惯性、实际聊天页回答导航和 Markdown 保存意图，留存浅深色与大字号截图。
