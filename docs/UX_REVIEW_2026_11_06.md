# 使用体验与视觉审查 — 2026-11-06

范围为现用的聊天、创作、下载和设置界面。故事模式已由用户明确标记为废弃功能，本轮不恢复其入口，也不将相关历史 UI 用例作为现用功能的验收要求。

## 本轮改动

| 发现 | 改动与用户可见结果 |
| --- | --- |
| 侧栏筛选与标题、数量挤在同一行；筛选按钮小，大字号下容易拥挤 | 全部、收藏、归档改用共用分段控件，每项至少 48 dp；三个现用工作区改为图标在上、文字在下的入口 |
| 搜索时键盘、导航和底部设置入口共同挤压结果区 | 输入期间收起工作区和底部设置入口，结果区保留滚动；空结果提供清除搜索和恢复全部范围的操作 |
| 查询或筛选变化后可能停留在旧的列表位置 | 新结果回到顶部；会话正文筛选结果缓存，避免装饰动画反复扫描历史消息 |
| 设置首页卡片边框和强调色重复，层级不够清楚 | 同类导航合并到分组面板，细分隔线对齐文字；组内图标使用中性色，保留操作按钮的强调色 |
| 设置搜索会随列表滚出屏幕 | 搜索固定在页头下方；支持键盘搜索动作，保留返回时的筛选和列表状态 |
| 模型切换主要依赖较矮的模型名称行 | 标题和模型组成一个至少 56 dp 高的点击区域，保留原有模型切换行为 |
| 输入提示叠加透明度后偏淡 | 使用完整的次级文字色，提高浅色、深色下的提示可读性 |
| 独立应用主题仅同步状态栏，导航栏仍可能跟随系统主题 | 状态栏和导航栏一起跟随应用主题；增加真实 MainActivity 上的浅色/深色切换检查 |

页面导航和关闭侧栏会清除输入焦点，避免搜索键盘滞留到下一页。既有纸墨配色、衬线阅读、模型请求、存储与签名保持原有约定。
