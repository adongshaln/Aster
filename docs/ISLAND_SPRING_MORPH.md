# 链接灵动岛：原位展开与 80/20 Spring

> 卡片外观与开合路径已由 [ISLAND_BLACK_ISLAND.md](ISLAND_BLACK_ISLAND.md) 取代；本文的 IslandSpring 曲线参数、窗口/焦点/短链与绘制预算规则仍然有效。

开发分支：`feature/island-spring-morph`。不改版本号，不合并 main，不改常驻光环的 shader、色板、线宽、64dp 画布或 25.5dp 圆心校准。

## 交互

- 原有点光环 → 获得窗口焦点 → 读取剪贴板 → 识别链接、分享展示入口继续复用。
- 新链接不再先等待 740ms 星冕动画。不隐藏光环后切换到状态栏下面的独立卡片。
- 同一个 `TYPE_APPLICATION_OVERLAY` 窗口，光环屏幕圆心保持不变。共享圆角轮廓从 13dp 内孔的圆心向整张卡片生长；卡片内容以实际测得的光环圆心作为 View pivot，同步从该点放大，不再做独立淡入或纵向滑入。
- 展开和收起使用完全相同的轮廓与内容映射，卡片四角在收起时一起汇聚回圆心；关闭尾段的单次回弹只作用于常驻光环，不让卡片发生负缩放。卡片背景、描边只由共享轮廓绘制一次，不叠加第二张固定尺寸卡片。
- 在开始之前扩大一次渲染画布，保留 2% 展开超调余量；布局完成才启动动画。收起结束后才恢复 64dp 小窗。光环子 View 始终是 64dp，不随父窗口变成椭圆或移动到新弹窗。
- 展开 600ms，收起 520ms，按压/释放 360ms，按钮按压/释放 260ms。所有状态切换使用同一弹簧插值；待机周期呼吸保留余弦外观（不是状态切换）。
- 超时、收起按钮、上滑、窗口外触摸、解析跳转都沿原路径收回。中途反向从当前渲染位置继续，不重置到预制端点；取消动画不执行旧结束回调。
- 短链解析不阻塞动画。过期/不同链接结果被丢弃，收起后不会重新弹出；动画中返回的文本在结束后更新缓存层，不重新启动展开动画。
- 剪贴板读取等待真实窗口焦点（800ms 超时释放焦点），不是固定猜测 180ms；只取有长度上限的文本/URI 字符串，不在主线程打开内容提供器。
- 跟随系统动画开关；关闭动画时直接进入目标状态。悬浮窗仍不可获焦，只有读取剪贴板时短暂获取焦点，不长期抢输入法/返回手势。

## 严格的曲线参数

`IslandSpring` 是无状态解析插值，不是逐帧 Euler 积分。以 Choreographer/ValueAnimator 的线性时间作为输入，60Hz、120Hz 和中途跳帧在同一时间点得到相同位置。

- 主形变分界 `a = 0.8`，尾段 `b = 0.2`；超调 `A = 0.02`。
- `r = -ln(A)/π`，`q0 = π/2 + atan(r)`，`eta = b*q0/(a*π)`。
- 欠阻尼弹簧响应 `R(q) = 1 - exp(-r*q)*(cos(q) + r*sin(q))`。
- 主段 `q = q0*Q(t/a)`，`Q(u) = 3u² - 3u³ + u⁴`。
- 尾段 `q = q0 + π*(S(v) + eta*H(v))`，`v = (t-a)/b`，`S(v) = 10v³ - 15v⁴ + 6v⁵`，`H(v) = v - 6v³ + 8v⁴ - 3v⁵`。
- `x(0)=0`，`x(0.8)=1`，`x(1)=1`；在约 `t=0.862` 只到达一次 `1.02` 峰值，之后缓慢回到 1，无第二次摆动。在 0.8 处位置/速度/加速度连续；两端速度与加速度为零。尾段最大速度约为主段的 18.3%。
- 几何不截断到 0..1；只限幅透明度、颜色等合法范围通道。收起时允许负进度的小幅回缩。

这是**时间重映射的解析弹簧响应**，不是恒刚度/恒阻尼的自由物理弹簧。固定 80/20、有限时长和一次回弹是设计约束。任意中断保留当前位置，但重新计时；不宣称任意中断时速度也连续。

## 绘制预算

- 动画帧不调用 `WindowManager.updateViewLayout`、不改变 `LayoutParams`、不重测文本。
- 复用 `Paint`、`Path`、`RectF` 和几何实例；岛体只画一个圆角黑色面并裁剪内容。
- 文本内容在运动期间使用独立硬件缓存；静止后释放，常驻光环保留小尺寸硬件层。
- 原 AGSL 色板只在 shader 建立时上传；失败后固定回退 Canvas，避免每帧抛异常。
- Canvas 回退的光晕数组预创建，不在 onDraw 中重复分配。
- 不固定 16ms 定时器、不按帧累加角度、不强迫系统高刷新率或绕过系统省电策略。按设备实际 vsync 运作。

## 验证

**禁止本地 Gradle 构建/测试。** 使用任务分支 GitHub Actions 的 Android build 执行 `testDebugUnitTest assembleRelease`。

新增测试覆盖：

1. 曲线端点、80% 分界、C2 连续、唯一 2% 回弹、尾段速度、60/120Hz 相同时间戳、长帧间隔。
2. 几何锚点、原黑孔尺寸、正超调、关闭尾段单峰光环回弹，以及共享卡片外轮廓在展开/收起时的 bounds。
3. 卡片四角以实际光环圆心为 pivot：进度 0 汇聚到圆心，进度 1 与共享外轮廓完全重合；关闭反向复用同一映射且内容缩放不为负。
4. View 回归：真实测量后的 pivot、卡片 bounds 与共享外轮廓包含关系、同窗固定 y / 光环尺寸、动画中窗口尺寸不变、快速反向、过期短链、销毁清理。

### 真机验收（仍需设备，不得以单测替代）

使用 CI 签名 APK，在 60Hz、120Hz 各跑至少 30 次展开/收起和快速反向：

- `adb shell dumpsys gfxinfo com.adong.adchat reset` 后操作，再保存 `adb shell dumpsys gfxinfo com.adong.adchat framestats`。
- Perfetto 采集 FrameTimeline、gfx、view、sched、freq，分析对应悬浮窗（应用不是前台时也需包含服务窗口），不要只测 Activity。
- 60Hz 帧预算 16.67ms，120Hz 帧预算 8.33ms。检查 CPU/GPU deadline、长帧、BufferQueue/SurfaceFlinger 是否及时呈现。
- 对齐开合首帧/末帧和慢动作录像，确认没有圆心位移、独立弹窗、闪黑、撕裂、裁边。检查关闭尾段回弹是否足够可见，不要仅凭数学曲线认定视觉验收。
- 覆盖深浅背景、键盘弹出、长链接、空/重复剪贴板、URI 剪贴板、短链慢网络、点后立刻收起、上滑起点在按钮上、TalkBack、动画倍率 0/0.5/1/2、横竖屏及字体大小。

源码层面消除已知卡顿来源，并不等于所有设备都已达到“零掉帧”。真机帧时间与视觉验证完成前，不能承诺 60/120fps 或零撕裂已通过。
