# 输入胶囊与内联建议（2026-10-25）

基线：`f286629`，仍为 4.1.0；分支 `codex/star-island`。

## 真机回访：Clawd 站位与星岛主题（2026-10-25）

- 用户截图显示：深色模式、输入胶囊收起时，三只小 Clawd 与大 Clawd 的脚底穿过输入框上边缘，整体站位偏低。
- 检查发现输入宿主已经对齐胶囊上沿，但 Clawd 容器另有 7 dp 下移；已在修复分支移除，包括资源加载占位层。大小 Clawd 与小 Clawd 同时对齐地面。
- 用户另反馈应用从深色切回浅色后星岛不变色。星岛独立运行且原先只读取系统 `uiMode`；应用自有主题切换不触发该配置变化。已在修复分支显式同步调色板，并覆盖墨线圈、卡片和操作按钮。
- 修复分支：`codex/clawd-island-theme-alignment`；仍需编译与定向回归验证，尚未发布。

## 交互

- 无焦点时输入框为居中小胶囊；聚焦后向两侧与上方弹性展开。壳体宽度、圆角与高度响应不同的弹簧，编辑文字保持正常比例。
- 编辑器始终是同一个 BasicTextField，保留光标、选区和输入法组合态。收起时展示单行草稿摘要；附件仍可查看和移除，长草稿编辑器仍保留。
- 输入建议直接显示为空输入框中的淡色文字，不进入草稿、不另占一行、不移动 Clawd。点发送直接把建议作为正常用户消息提交；输入任何内容立即取消旧建议。停止生成、附件导入和配置缺失等状态优先于建议。
- 展开后显示思考滑块，根据现有 ReasoningPolicy 暴露各模型支持的档位；“自动”独立选择，不假定模型默认等于最低档。触摸拖动连续跟手，档位间可经过但不能停留；松手后弹性吸附到最近的受支持档位并写入设置，键盘与辅助功能仍按离散档位操作。
- 用户进入最高档时在滑轨附近播放一次星芒与流光，之后保留静态色晕；没有无限粒子动画，遵守系统关闭动画设置。协议字段与模型档位映射沿用现有实现。

## 建议质量与状态

- 从最近两轮完整文本中提取上下文，长用户消息和回复同时保留开头与结尾；不携带图片、推理内容或工具结果。
- 提示词改为可直接发送的具体下一步请求，允许返回无建议，不替用户回答、虚构个人信息或泛泛追问。
- 拒绝重复、列表、多行、明显助手口吻、无意义追问和超长输出；超长内容不再硬截成半句。服务端明确标记未完成时也不展示。
- 输出预算 128 tokens、最长等待 10 秒；沿用配置的建议模型及其最低支持思考档位。
- 建议绑定会话、最后完整回复和建议服务配置。输入、再次发送、切换模型、关闭功能、修改配置后清除旧结果；重复点击不能重复发送。
- 提示词与过滤可以减少已知问题，实际建议是否合适仍取决于所选模型与对话内容；本轮不调用付费模型做主观打分。

## Clawd

- 活动带直接锚定输入壳体的实际窗口坐标及宽度，不再依赖包含工具和附件的外层高度。
- 窄胶囊两端为圆角保留空间；展开与收起时 Clawd 和活动带同步移动，淡色建议不触发输入动作。
- 物理坐标使用绝对横坐标，绘制子树固定 LTR，避免 RTL 布局镜像后点击位置与像素角色分离。
- 调整尺寸期间保留相对位置，不逐帧保存位置；恢复全宽后不因取整而累积漂移。

## 参考图修订：临时思考浮层与阅读字重

- 用户提供两张参考图后，移除展开输入框底部常驻的思考滑块；工具栏仅保留“思考强度”胶囊入口。
- 点入口在上方打开独立 Popup，中心显示档位与模型，下面为粗胶囊轨道、离散节点和白色圆形滑块。普通档位使用陶土色，最高档使用紫粉渐变和有限时长的星点流光。
- 浮层不参与输入框测量，不推动 Clawd；点外部、返回、开始输入、生成开始、收起输入框时关闭。滑动松手保存，允许继续比较档位；模型行可直接打开模型选择器。
- 再点入口关闭浮层：透明浮层触摸层覆盖入口与卡片，避免一次手势先触发外部关闭、再穿透触发入口重开；窗口不抢输入焦点。
- 滑轨使用连续浮点位置绘制，普通与最高档填充都跟随拇指；松手后用弹性插值吸附最近档位，只提交已有的模型支持值。
- 阅读正文改用 Medium：在用户设置的基础字重上增加 60（默认 650 对应正文轴 710），Semibold/Bold 分别加 110/160，最高限制 900。每档提供真实可变字体实例，去掉流式/Markdown正文强制 Regular 覆盖；仍可通过设置调整基础字重。
- 本地 Release 与原生测试代码编译通过，未增加模拟器轮测；按原流程提交后生成签名安装包。
- 思考强度修订：debug app 与两项定向 Android UI 回归测试均编译通过；Release assemble 通过。回归测试未在设备上执行。
