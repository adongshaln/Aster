# 链接灵动岛：墨线扣眼与纸签（Claude 风格）

开发分支：`feature/island-black-island`。本文取代 `ISLAND_BLACK_ISLAND.md` 的外观与动效；窗口、焦点、剪贴板、短链、关闭窗口移位动画等规则不变。交互原型：[island-claude-prototype.html](island-claude-prototype.html)（用本地 http 服务打开以加载 App 自带衬线字体）。

## 设计

- **常驻：一笔画成的墨线圈。** 摄像头外 13dp 黑色底圈 + 陶土色墨线（半径 15.4dp，笔重 2.1dp）。落笔、收笔渐细，中段饱满，起止交叠 12°，半径带 ±0.5dp 手工抖动。不发光；待机只做 0.95±0.05、5 秒周期的透明度呼吸（硬件层，只改 alpha）。位置、尺寸固定。
- **展开：纸签从扣眼里抽出。** 先横向抽出与黑色底圈等高的纸带，再向下坠，顶边同时上抬 8dp 让出墨线圈；高度带一次明显回弹，宽度轻微回弹。墨线圈全程留在纸签顶部正中，作为扣眼。
- **收起：** 先收高度、再收宽度，纸签退回扣眼；宽度小于 40dp 时墨线"咽"一下（笔重 +30% 后回落）。
- **按下：** 墨线加重到 1.45 倍（只向外长），松手回落。
- **剪贴板为空/重复：** 墨线圈弹动两下（缩放峰值约 1.10、1.09，只向外，不小于 1），两次触感各落在一次峰值上（+43ms、+203ms）。
- **跟随系统深浅色。**

- 纸签：宽 `min(屏宽, 440dp) − 28dp`，圆角 40dp，内边距 上 44 / 左右 18 / 下 18dp；顶边在墨线圈圆心上方 21dp。投影半径 14dp、下移 6dp（API 28+），随纸签变宽从 0 渐入。
- 排版：38dp 圆形 well 底 + 20dp 字形（ink 86%）；标题为 App 自带 Noto Serif SC 可变字体 wght 560、16sp；摘要 13sp 无衬线 muted 单行中间省略；按钮 44dp 高等宽、间距 10dp、圆角 22dp，"收起" well/ink，"解析链接" clay/onClay，14sp sans-serif-medium。
- 内容：透明度 = smoothstep(0.34, 0.84, 高度进度)；缩放由独立弹簧从 0.9 到 1（滞后 0.12s）；API 31+ 叠加 (1−透明度)×6dp 的模糊；被纸签轮廓裁切。

## 动效：解析阻尼弹簧

`IslandJellySpring`：以绝对时间（秒）求闭式解，不逐帧积分，60/120Hz 与掉帧取样一致；改目标（含延迟改目标）时以当前位置和速度为初值，所以中途反向保有动量。`response` 为无阻尼周期（秒），`damping` 为阻尼比。

x(t) = e^(−ζω₀t)·(x₀·cos ω_d t + (v₀ + ζω₀x₀)/ω_d · sin ω_d t)，ω₀ = 2π/response，ω_d = ω₀√(1−ζ²)。

| 弹簧 | 展开 | 收起 |
|---|---|---|
| 宽度 | response 0.44，ζ 0.76，立即 | response 0.396，ζ 0.82，延迟 0.048s |
| 高度 | response 0.52，ζ 0.64，延迟 0.06s | response 0.4056，ζ 0.76，立即 |
| 内容缩放 | →1，response 0.42，ζ 0.62，延迟 0.12s | →0.9，response 0.3，ζ 0.9 |
| 墨线笔重 | 按下 →1.45（0.24, 0.6）；松手 →1（0.34, 0.42）；收起"咽"：kick +7/s（0.3, 0.42） | |
| 墨线缩放 | 空剪贴板：kick +5/s，0.16s 后再 kick +5/s（0.22, 0.45），绘制时取 max(1, 值) | |

果冻挤压（体积近似守恒）：vw = 宽度速度 × 0.44 / 宽度行程，vh = 高度速度 × 0.52 / 高度行程（均限幅 ±1）；
渲染高 = max(种子, h − 0.8·vw·0.12·max(0, h − 0.6·种子))，渲染宽 = max(种子, w − 0.8·vh·0.05·max(0, w − 种子))。种子 = 26dp。

窗口：展开前一次放大到 `宽 × (纸签底 + 0.12 × 高度行程 + 28dp)`，收起静止后一次缩回 64dp；动画中不改 LayoutParams。

## 实现结构

- `IslandJellySpring` / `IslandJellyBody`（纯 Kotlin，可单测）：弹簧与纸签几何。
- `IslandInkRing`（纯形状函数）/ `IslandInkRingView`（64dp 视图）：墨线圈。
- `IslandPalette` / `IslandTypefaces`：令牌与衬线字体（与主题共用缓存文件，按原始资源长度校验完整，复制走临时文件再原子改名；后台线程加载）。
- `IslandSurfaceView`：纸面、细边、投影，并裁切内容。
- `IslandView`：一个 `TimeAnimator` 帧时钟驱动所有弹簧；全部静止即停。删除 `IslandGlowView`、`IslandMorphGeometry`。

验证：禁止本地 Gradle，以 CI `testDebugUnitTest assembleRelease` 为准；视觉与手感在真机确认。
