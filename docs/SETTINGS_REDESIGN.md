# 设置与果冻动效重做（2026-10-25）

基线：`01a49cc`，版本仍为 4.1.0，分支 `codex/star-island`。

## 本轮行为

- 设置首页改为搜索与分类导航：模型与连接、使用体验、应用管理；每项显示当前配置摘要。具体参数在专页编辑，返回保留搜索、目的页与滚动位置。
- 服务卡点击即可编辑；测试、复制与删除放在更多菜单中。删除仍显示受影响的历史对话并确认。
- 接口格式移到地址和密钥附近；模型 ID 合并成一个可输入、可从同步列表选择的字段；高级接口路径仍默认折叠。
- 默认对话模型真正保存到应用默认配置，供新对话和星岛读取；历史对话保持自己的路由和草稿。输入建议增加明确的关闭选项。
- 星岛的设置入口直达星岛专页。主题三选在一行呈现，缩略图使用图形而非挤压文字。
- 编辑期间的连接测试只回填仍匹配连接的模型信息，不覆盖用户继续修改的字段；保存、退出或删除后迟到的测试结果失效。

## 动效与颜色

- 小控件快速按压，释放时横纵轴使用不同弹簧参数；共享按钮的命中范围保持稳定。
- 分段控件由一个胶囊连续移动，两侧响应速度不同，拉伸限制在轨道内，支持 RTL。
- 页面短距离弹性进入、快速退出；设置子页和高级分组采用共享弹簧。常驻装饰漂浮收敛为一次落位。
- 输入框、流式正文和长消息正文保持稳定；果冻感集中于用户主动操作。下载进度用真实百分比及不超调的视觉插值；下载状态切换保留预览和 WebView。
- 系统关闭动画时，共享装饰和持续动画直接显示静态状态。
- 深色主题使用完整 darkColorScheme，并为强调、错误、主按钮等颜色补齐配对前景；移除选择器和设置中的固定白底、白字。
- 抽屉仅接受起始边缘向内拖动，避免与正文和媒体的横向手势冲突。

动效依据：[Compose 自定义动画](https://developer.android.com/develop/ui/compose/animation/customize)。弹簧适合中途打断后继续衔接；颜色和大范围布局使用更高阻尼，避免视觉振荡。
