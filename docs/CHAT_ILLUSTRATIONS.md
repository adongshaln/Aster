# 剧情插图（实验）

入口：聊天输入框的「输入选项」→「剧情插图 · 实验」。默认关闭，只作用于当前会话。首次发送前的开关状态随草稿恢复，创建会话后保存到该会话；后续新会话默认关闭。

每次完整文字回复结束后，使用生成该条回复的聊天渠道和模型，额外提炼一次画面；再使用发送该轮消息时选定的剧情插图专用服务，调用固定模型 `nai-diffusion-5-full`，生成一张 1024×1024 插图。原渠道不支持该模型时显示错误，不自动换模型。绘图不阻塞继续聊天，也不改动主聊天请求。

## 独立服务配置

在聊天「输入选项」中点击「配置剧情插图服务」，或进入「设置 → 服务与连接 → 剧情插图服务」。可以选择已有服务，或者点击「新建专用服务」独立填写名称、Base URL、API Key、绘图接口路径和额外请求头；保存后自动绑定剧情插图。密钥使用现有的加密存储。

剧情插图服务与普通绘图服务分别保存。切换任何一方不会改变另一方；运行中的任务继续使用提交时选定的服务。删除当前插图服务后，需要明确重新选择服务，不会自动把后续插图请求转发到其他渠道。首次升级从原来的绘图服务初始化一次，保留已有用法。

如果主动选择复用已有服务，编辑它的地址与密钥也会影响其他使用该服务的功能；要使用独立地址和密钥，请新建专用服务。

画面选择以本轮完整回复为主，结合最近必要对话、全局角色/故事设定和上一张插图焦点。提炼输出包括中文标题、焦点描述和适合 NAI V5 的英文画面提示词。沿用原聊天模型，不将提示词注入模块的安全绕过控制指令接入新增的提炼/绘图调用。

## 交互与保存

- 对应回复下方显示提炼、排队、绘图和保存状态。完成后点击图片可缩放预览，也可保存到相册。
- 插图按会话、回复和正文版本绑定；切换模型或会话不会把结果插到新对话。
- 失败保留正文和已提炼的提示词。再次点击重试时，只要提示词已存在就跳过文字分析。重试绘图仍可能产生绘图费用；未确认的网络响应会显示相应说明，不自动重发。
- 停止等待、关闭开关、编辑截断、删除原会话或重新生成回复会停止对应的本地任务，拒收过期结果。停止等待不代表供应商已停止处理。
- 重启应用后，未完成任务显示为中断，等待手动重试；不会自动再次请求。
- 图片下载到独立的 `chat-illustrations` 私有目录，避开作品库的清理规则。编辑或重新生成时移除已弃用图片；删除会话时保留撤销所需的图片，后续启动清理超过一天且无会话引用的缓存。
- 插图数据与用户上传附件分开存储，不自动发给后续聊天请求。兼容旧会话记录。

## Gemini Argon 提炼预算修复（2026-11-07）

原先提炼请求统一限制为 1,200 Token，可能在推理模型产出正文之前耗尽。现为 Gemini 4 提供 32,768 Token 上限，其他已识别推理模型为 8,192，普通模型为 4,096；如果用户为该聊天模型配置了更低的最大输出，则遵守该限制。这里增加的是允许的思考和输出余量，画面提示词依然要求简短，不更换原聊天模型，也不改变主聊天请求。

只对新增的提炼请求检查输出结束状态：预算耗尽、明确拒绝、不完整响应或服务端错误时停止，不把思考内容或截断文本当作绘图提示词。卡片错误说明会标明提炼或绘图阶段；不会自动重发付费请求。

增量验证共 4 项：Argon 请求余量及原模型保持、思考耗尽预算且遵守用户限制、服务错误与截断响应不作为绘图提示词、既有绘图失败重试流程。均使用模拟服务；没有取得用户原始失败响应，真实渠道仍需在原卡片点击重试确认。

## 当前对话认证与提炼流式兼容（2026-11-07）

自动提炼使用该轮聊天请求的服务、Key、接口路径、模型与思考档位，不再自动降低提炼的思考档位。此前手动重试从卡片读取旧的聊天服务与模型；现改为在需要重新提炼时读取当前对话的完整连接配置，并更新卡片的提炼来源。已经生成提示词的绘图重试仍直接复用提示词，不额外调用聊天模型。在途任务继续使用启动时的配置，避免切换会话后串流。

Chat Completions 提炼改为与普通聊天相同的流式传输，同时兼容服务端返回非流式 JSON；只累计正文，不把思考内容作为提示词，不启用工具或自动续轮。已有 Responses、Anthropic 提炼路径保持原解析。错误信息提供提炼服务名称、模型、结束原因及是否仅收到思考，不输出 Key、聊天原文或思考正文。

6 项针对性检查通过：4 项提炼完成/流式响应检查，以及 2 项会话来源与重试检查。测试使用不同的虚拟 Key 和接口路径，确认提炼请求、重试请求和绘图请求的认证头归属；没有读取手机密钥或发送真实模型请求。

## 提炼返回格式诊断（2026-11-07）

读取手机当前错误后确认，最新失败已经到达画面计划解析阶段。一次受控重试的结构诊断显示，模型返回 317 字符的普通说明，没有 JSON 对象、字段或代码围栏；不属于网络中断，也不能作为绘图提示词直接发送。

解析器现在兼容 JSON 外的说明文字、Markdown 围栏、双重编码的 JSON 字符串及字符串内的括号。只接受实际包含 `prompt` 字符串的完整画面对象；不从思考块中提取示例，也不把自然语言说明直接交给绘图。

未返回画面对象时，卡片显示服务返回的可见正文片段（最多 800 字符，移除思考块并遮盖常见凭证格式），便于明确区分模型说明与格式错误。临时的结构日志已移除，不输出正文或密钥到系统日志。新增 3 项针对性格式检查通过，未跑全量测试。
