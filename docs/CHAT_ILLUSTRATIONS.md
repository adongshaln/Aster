# 剧情插图（实验）

入口：聊天输入框的「输入选项」→「剧情插图 · 实验」。默认关闭，只作用于当前会话。首次发送前的开关状态随草稿恢复，创建会话后保存到该会话；后续新会话默认关闭。

每次完整文字回复结束后，使用生成该条回复的聊天渠道和模型，额外提炼一次画面；再使用发送该轮消息时选定的绘图渠道，调用固定模型 `nai-diffusion-5-full`，生成一张 1024×1024 插图。原渠道不支持该模型时显示错误，不自动换模型。绘图不阻塞继续聊天，也不改动主聊天请求。

画面选择以本轮完整回复为主，结合最近必要对话、全局角色/故事设定和上一张插图焦点。提炼输出包括中文标题、焦点描述和适合 NAI V5 的英文画面提示词。沿用原聊天模型，不将提示词注入模块的安全绕过控制指令接入新增的提炼/绘图调用。

## 交互与保存

- 对应回复下方显示提炼、排队、绘图和保存状态。完成后点击图片可缩放预览，也可保存到相册。
- 插图按会话、回复和正文版本绑定；切换模型或会话不会把结果插到新对话。
- 失败保留正文和已提炼的提示词。再次点击重试时，只要提示词已存在就跳过文字分析。重试绘图仍可能产生绘图费用；未确认的网络响应会显示相应说明，不自动重发。
- 停止等待、关闭开关、编辑截断、删除原会话或重新生成回复会停止对应的本地任务，拒收过期结果。停止等待不代表供应商已停止处理。
- 重启应用后，未完成任务显示为中断，等待手动重试；不会自动再次请求。
- 图片下载到独立的 `chat-illustrations` 私有目录，避开作品库的清理规则。编辑或重新生成时移除已弃用图片；删除会话时保留撤销所需的图片，后续启动清理超过一天且无会话引用的缓存。
- 插图数据与用户上传附件分开存储，不自动发给后续聊天请求。兼容旧会话记录。
