## 2. 已落到代码的规则

- 浅色画布 `#F5F3EF`、纸面 `#FFFDFA`、内嵌面 `#EDEAE4`；深色画布 `#171715`、纸面 `#232320`。`Theme.kt` 统一提供，星岛通过 `IslandPalette` 转换为原生颜色。
- 主操作使用 `Ink / OnInk`；陶土保留作品牌与少量强调。新增文字专用 `AccentInk`，浅色 `#A34B35`、深色 `#EBA88E`，避免把装饰色直接用于细小文字。
- `AsterShape` 提供 10 / 14 / 16 / 20 / 24dp 的图标、控件、内容、卡片、编辑区域轮廓，弹层顶角 32dp；胶囊、输入壳体和星岛保留专用几何。没有全量机械替换所有合法圆角。
- 公共主按钮与胶囊按钮保留至少 48dp 高度；工具项与开关保留标签、开关角色和状态语义。字重、标题与分组标签按内容层级使用。
- `rememberAsterClick` 在点击成立后请求触感；主工具、设置及公共按钮使用同一交互源识别按压。无交互源的旧按压修饰器先等待系统点击阈值，滑动取消时撤销，不再在原始落指时震动。
- 保留已有的输入弹簧、原生星岛弹簧、窗口缓冲与重内容首帧渐显。工作区选中动画放在独立组合范围内，避免它逐帧带动历史筛选；前景色根据动画中的实际底色选择。

主要入口：`ui/theme/Theme.kt`、`AsterApplePhysics.kt`、`AsterShape.kt`；`ui/components/AsterDesign.kt`、`ConversationUi.kt`、`AsterSectionLabel.kt`；`MainActivity.kt`；`ui/screens/` 与 `island/`。

## 3. 同时修复的交互问题

**回看历史时聚焦输入框。** 原判据把历史中途被视口裁切的行误认成“接近末尾”。现在要求真正的最后一项已经进入视口，再计算剩余溢出。设备检查用真实阅读拖动退出自动跟随，回到第一条，聚焦输入后仍停留在第一条。

**无脚本授权的 HTML 状态栏。** 只给内部高度测量脚本生成随机 nonce；卡片原始脚本、事件属性及 JavaScript 链接不获得执行授权。隔离 iframe 不授予同源能力，原生仅暴露 `onHeight`，不暴露动作或 RPC。高度消息校验来源，保留回调失效和高度合并机制。已授权 helper 的原有消息处理方式保持兼容。

实际 Chromium 中，折叠 → 展开 → 收起的高度记录为 **64 → 152 → 64**，动作调用为 0。手动打开 RP 的状态栏，时间、地点、天气三行完整显示。无自定义背景的 HTML 使用主题默认前景；声明自身背景的卡片保留浏览器默认明暗配对，自定义 CSS 优先。

## 6. 对比条件与实际边界

- 正文、表格、工具与模型选择使用同一组本地样例。旧首页截图带有临时模型 Snackbar，新版等提示消失；问候文字随会话变化。空输入对比另补 `02b`，有效草稿 `02` 单独展示，避免将启用/禁用颜色差异误当成优化。
- 旧侧栏没有历史，新版补入 3 条本地记录以检查置顶与长标题；其内容差异在对比中注明。星岛屏幕提问使用本地绘制的选区夹具，验证窗口和排版，不代表已执行真实截图授权或在线问答。
- 完成了主页面与代表性弹层的首版升级。次级服务编辑、技能管理、预设、长错误和所有附件状态没有逐个手动验收；它们继承公共设计，不列为独立重设计完成项。废弃故事模式没有恢复。
- 本轮没有在线请求，因此不以此证明模型响应效果、下载成功或插图服务可用；相关业务实现未改动。中文组合输入与真机触感、不同尺寸/大字号、真实流式回复中的性能仍需对应设备体验。
- 软件模拟器只支持布局、点击、轨迹和窗口检查。没有真机帧率数据，也不对“完全无卡顿”作结论。当前没有连接手机，未进行本次真机安装。
- 没有推送 GitHub、合并 main 或发布正式版本。后续按用户要求安装/发布时沿用签名，并按仓库最新版本顺延编号。
