# 链接灵动岛：单一黑色岛体

开发分支：`feature/island-black-island`（基于 `feature/island-spring-morph`）。不改版本号。
本文取代 `ISLAND_SPRING_MORPH.md` 中的卡片外观与开合路径；`IslandSpring` 的 80/20 曲线、窗口/焦点/短链/绘制预算规则仍按原文执行。

## 外观

- 只有一个纯黑（`#000000`）岛体，大圆角 40dp。无描边、无顶部横条、无嵌套链接胶囊、无渐变底色。
- 岛体顶边固定在原黑孔顶边（光环圆心上方 13dp），摄像头位于岛体顶部正中。内容从岛体顶边下方 36dp 开始（26dp 黑孔 + 10dp 间隙），顶部这一带只留给摄像头。
- 宽度沿用原视口：`min(屏宽, 440dp) - 28dp`，水平居中于光环圆心。

- 字体：系统无衬线。标题 `sans-serif-medium` 15sp，摘要 `sans-serif` 13sp，按钮 `sans-serif-medium` 14sp；不用 fakeBold。
- 灰白层次：标题 `#F5F5F7`，摘要 `#8E8E93`；“收起”深灰底 `#2C2C2E` + `#F5F5F7` 字；“解析链接”近白底 `#F5F5F7` + 黑字。
- 同心圆角：按钮半径 22dp = 岛体半径 40dp − 边距 18dp。
- 平台图标：Material Rounded 字形（与下载页一致），白色字形放在平台色圆角方块里。抖音 `#2F6F62` 音符，B 站 `#D45C78` 播放屏，X `#3D586E` @，其他 `#3A3A3C` 链接。
- 标题：抖音视频 / B 站视频 / X 媒体 / 媒体链接。摘要：去掉协议、开头的 `www.`、末尾 `/` 的单行链接，过长时中间省略。

## 开合路径

同一个主进度 `p = IslandSpring.progress(t)`（展开 600ms，收起 520ms；收起时 `p` 取 `1 - spring`）。岛体形状、内容、光环全部是 `p` 的纯函数，所以收起与展开严格同路径，中途反向从当前形状接续。

| 通道 | 函数 | 说明 |
|---|---|---|
| 宽度 `W(p)` | `s = clamp(p / 0.55)`，`W = 1 - (1 - s)²` | 先横向舒展，`p = 0.55` 时减速到全宽并停止；不参与回弹 |
| 高度 `H(p)` | `s = (p - 0.30) / 0.70`；`s ≤ 0` 为 0；`0 < s ≤ 1` 为 `s²(1.5 - 0.5s)`；`s > 1` 为 `1 + 1.5(s - 1)` | `p = 0.30` 起向下加高；末端斜率 1.5，承接主曲线唯一一次 2% 超调（约 +5dp）|
| 圆角 | `min(40dp, 高/2, 宽/2)` | 先是 26dp 高的横向胶囊，再长成大圆角矩形 |
| 内容 | `c = smootherstep((clamp(H) - 0.25) / 0.65)`；透明度 `c`，缩放 `0.94 + 0.06c`（支点：光环圆心 x、岛体顶边） | 内容随岛体展开，被岛体轮廓裁切；回弹段不动 |
| 光环透明度 | `1 - smoothstep(0, 0.12, max(p, 0))` | 展开头段淡出；收起末段在岛体回到黑孔时接续出现 |
| 收起尾段 | `recoil = clamp(-p / 0.02)`，光晕亮度 + `0.32 × recoil` | 收起的唯一一次回弹表现为光环一次亮度脉冲 |

- 形状不外推到负进度：`p < 0` 时岛体就是原黑孔。
- 常驻光环的位置与尺寸在开合全程固定：`springScale` 只回到 1（打断按压时从当前值收回），不再放大到 1.28，也不再用尺寸做收起回弹。

时间线（600/520ms，364×150dp 卡片）：

- 展开：60–210ms 横向从 26dp 舒展到约 357dp，同期光环 60–120ms 淡出；180–480ms 向下加高到 150dp；270–390ms 内容淡入；约 510ms 底边多出约 5dp 后回落。
- 收起：0–230ms 先收高度（内容 60–150ms 淡出），180–416ms 再横向收回黑孔，300–416ms 光环接续出现，416–520ms 光晕一次脉冲。
