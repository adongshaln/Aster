# Aster 2.1 界面预览

基线：Aster 2.0.0 / 52，`7077966`。开发分支：`design/aster-2.1`。
测试版本：2.1.0-preview.1 / 53。经过真机确认后再合并 main、维护正式 CHANGELOG。

## 设计方向

暖白底色、浅棕强调色、墨色主操作，使用原有星形标志。
统一字体层级、48 dp 常用图标操作、页面标题、分段选择器与卡片边界。
减少装饰性容器，给阅读与创作内容更多空间。

## 本次变化

- 导航：主要功能移至侧栏顶部，设置固定在底部；历史对话按时间分组。
- 聊天：开放式正文布局，助手标志位于正文上方；用户消息采用柔和底色。
  首页建议先填入草稿并聚焦，允许编辑后发送；顶栏直接新建对话或选择模型。
- 创作：图像创作与漫画翻译采用明确的模式切换；画面参数默认折叠，并显示当前选择。
- 下载：链接输入、粘贴、识别平台与解析按钮形成连续操作；统一下载列表与空状态。
- 设置：模型分配、服务连接、助手偏好分区；导入导出归入配置管理。
  连接状态依照实际测试结果显示，不把配置存在视为连接成功。
- 切换页面保存滚动和可保存的局部状态；非聊天页面返回键回到聊天。

## 回归边界

保留原包名、数据结构、API 协议、工具执行、固定签名与发布流程。
保留胶囊的单一动画进度、键盘收起时清除焦点、每次 IME 更新跟随消息底部、
底部覆盖导航区的渐进 Haze，以及滚动和流式输出期间的轻量效果。

## 验证

现有 Android build 工作流执行单元测试并构建固定签名 APK。
Native UI preview 工作流在 Android 35 / 360 dp 手机模拟器上检查主要页面、
可编辑建议、键盘展开与收起、画面参数展开，并输出原生截图。
测试使用虚构内容，不连接模型服务。

真机需重点体验：长回复滚动、连续开关键盘、手势导航区域、流式输出期间的帧率。
模拟器截图无法代替真机流畅度验收。
