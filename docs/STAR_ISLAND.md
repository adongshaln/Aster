# 星岛

原“链接灵动岛”扩展为按需处理剪贴板内容的入口，保留墨线圈、纸签及原位开合动画。

## 墨线展开动效

墨线圈现在直接延展为卡片边框。展开时由同一条轮廓绘制墨线、填充纸面并裁切内容；小圈不再与新出现的矩形各自动画。镜头的黑色底圈全程保持原位和不透明。

横向牵引略先于下坠（28 ms），肩部和底边根据弹簧速度产生不对称的柔软弯曲，最终恢复平整。纸面逐渐填入，文字稍后出现，仅从 0.96 缩放至 1，避免正文随着外框明显拉伸。边框收敛到约 1 dp 的浅陶土墨线，保留轻微笔压变化。

收起沿相同轮廓回拢，最后墨线轻轻回弹。中途反转沿用当前位置和速度，不重置动效；关闭系统动画时直接到达终态。整段动画共享一只帧时钟、复用路径和坐标数组，不逐帧修改悬浮窗尺寸；触摸范围跟随真实轮廓。

动效验证：26 项轮廓、弹簧形变和悬浮窗检查通过；调整内容渐显时机后复查相关 23 项通过。实际 Kotlin 坐标导出的浅深色预览检查了展开、收起及中途反向；没有异常轮廓自交或侵入镜头黑芯。Release 构建通过。尚未安装这一轮动效到手机，最终触感以实机体验为准。

## 使用

在设置中开启“星岛”，依次授予悬浮窗和通知权限。复制内容后点按墨线圈，选择操作：

| 内容 | 操作 |
| --- | --- |
| 文字 | 翻译、润色、解释 |
| 普通 HTTP(S) 网页 | 阅读网页、打开原页、复制链接 |
| 已支持媒体链接 | 解析下载、打开原页、复制链接 |

### 触摸兼容模式

若系统升级后墨线圈只剩最下侧能点击，在星岛设置中启用「触摸兼容模式」，再到系统无障碍设置手动开启「Aster · 星岛触摸兼容」。墨线圈继续停留在摄像头旁。

此模式用无障碍悬浮窗承载原来的星岛界面，没有订阅界面事件，也不申请读取其他应用界面节点、监听按键或执行手势的能力。只在用户点按时读取剪贴板的规则不变。关闭服务即恢复普通悬浮窗，切换时保留当前卡片、输出及正在执行的任务。关闭星岛主开关仍会移除窗口；兼容窗口在熄屏和锁屏期间隐藏。

新增的屏幕提问会声明单次截屏能力（`canTakeScreenshot`），只由用户长按触发；仍不读取界面节点、不订阅其他应用事件。系统服务说明与应用内设置同时说明截屏用途。已有服务若未获得新能力，需由用户在系统设置中重新开启，应用不会代为授权。

2026-10-29 真机定位（澎湃 4 / Android 17）：系统 StatusBar 的触摸区域覆盖顶部 152 px；普通星岛窗口为 y=-21…187 px 且层级低于 StatusBar，只剩底部 35 px 接收触摸。应用窗口自身没有丢失触摸区域，扩大点击范围或改负偏移无法解决系统窗口截获。兼容模式使用系统提供的 `TYPE_ACCESSIBILITY_OVERLAY` 与已绑定服务的窗口 token，并以屏幕坐标保持原镜头中心。

### 长按框选与快捷提问

Android 11 及以上版本，开启星岛无障碍服务后：

1. 长按收起的墨线圈。墨线先轻轻沉入镜头，再截取一次当前画面。
2. 在冻结画面上拖动框选；边角可调整大小，框内可移动选区，可重选或取消。
3. 点「就问这里」，选择层沿墨线回缩到镜头；选区在本机裁剪后，较大的问答卡片再从同一个圈展开。选择层与问答卡片复用同一套果冻弹簧、墨线轮廓和镜头黑芯，截图随轮廓展开而逐步显露。
4. 输入问题并发送，默认对话模型接收选区图片与问题，回答在卡片内流式显示。模型需支持图片输入；可以围绕同一选区追问、停止或复制回答。

「收起」保留选区、草稿、回答和正在运行的请求，再点墨线圈可恢复；「结束」取消当前问答并释放这次选区与上下文，恢复剪贴板点按入口。重新长按可以开始新的截屏；取消框选不会丢失此前的问答。旋转屏幕、锁屏、关闭服务会撤销未完成的框选，避免坐标错位或锁屏暴露截图。

完整截图和选区只暂存在内存，不写入相册、文件或普通聊天记录。只有点发送才向配置的对话接口上传**裁剪后的选区**；图片最长边限制为 1600 px，JPEG 质量 90，问题限制 2,000 字符。追问最多携带此前四轮问答，每次请求只附带一份选区图片。沿用星岛单轮请求、取消与输出上限，不启用技能、工具、联网搜索或自动续写。受系统保护的页面不能截取，不尝试绕过。

键盘显示时，卡片调整可用阅读高度而不移动镜头锚点；空间不足时收起预览行。旧回答与当前流式回答分开布局，避免每个片段都重新排版全部历史。

### 剪贴板处理

中文默认译为英文，其他主要语言默认译为简体中文。润色保留原语言和含义；解释使用简体中文。模型处理使用设置中的默认对话接口，不读取聊天历史、不创建会话，也不修改草稿与附件。

结果在星岛内流式显示，可停止、复制或返回选项。完成、停止和失败的结果保留至手动收起；普通选项页在无操作 12 秒后收起。结果区可滚动，标题区域可上滑收起。相同剪贴板内容可以再次处理。

## 行为边界

- 只在用户点按时读取剪贴板，不后台监听；剪贴板材料仅在选择模型操作时发送，屏幕选区仅在主动发送问题时发送。
- 网页阅读先抓取真实正文，再生成摘要。跳转、正文大小和时间均有上限；不执行网页脚本、不携带浏览器登录信息、不访问本机与局域网。无法读取时明确报错。
- 普通网页地址保留原查询参数，预览隐藏查询及片段信息。多链接文字按第一个 HTTP(S) 地址提供链接操作。
- 剪贴板文字最多 16,384 字符，超长时明确提示。网页提取最多 16,000 字符，截断时明确注明；结果达到 16,384 字符自动停止并保留内容。
- 关闭、返回或换内容会取消请求并使旧回调失效；点击停止则保留最后收到的文字。切换主题、旋转或调整字体会重建视图并保留当前请求。
- 星岛关闭技能、搜索、文件创建及自动续写。仅推理而无最终正文时显示未完成，不额外发起续轮请求。
- 保留原服务组件、权限偏好和通知渠道 ID，升级沿用原开关及权限。
